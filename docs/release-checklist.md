### F5. 尚存风险与发布限制

1. **真实模型调用未在整改后重跑**（本报告最重要的限制）。整改触及了模型输出的归一化
   （`normalizeModelFacts`），理论上会让"模型返回越界值"的图片从「不通过」变为「未判定」——
   这正是修复目的，但也意味着**历史分数不能直接当作整改后的分数**。发布前若要给出确定结论，
   建议跑一次 `node src/cli.mjs samples --save --cost`（约 $0.025）复核。
2. **Node 20 未本地验证**，仅由 CI 矩阵声明。
3. **JPEG/WebP 的实测指标缺失**是设计选择，不是缺陷，但会让部分规则永远停在「未判定」。
4. **无鉴权 + 只监听本地**：适合作品集演示，不适合直接部署。
5. **推翻日志会改变演示结果**：`data/feedback.jsonl` 有记录时样例分数会漂移（已在 README §13 说明）。
